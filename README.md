Team Structure
--------------
Person 1 → Public + Auth
Person 2 → Student
Person 3 → Organization + Mentor + Admin

Rules
-----
1. Do not push directly to main.
2. Create a feature branch.
3. Use shared UI components.
4. Do not duplicate components.
5. Use mock data from src/data.
6. Keep pages responsive.
7. Test before creating a PR.
8. Every PR needs one review.
9. Resolve merge conflicts yourself before requesting review.
10. Do not modify another person's feature without discussing it.

Branch naming
-------------
